基础知识/ C++

智能指针与异步生命周期

从所有权语义到异步回调，理解 shared_ptr、weak_ptr 与对象的生存边界。

用类型表达所有权

类型所有权语义
T* / const T*可空借用，不管理生命周期
T& / const T&不可空借用，不管理生命周期
std::unique_ptr<T>独占所有权，可以转移，不能复制
std::shared_ptr<T>共享所有权，复制会增加强引用计数
std::weak_ptr<T>非拥有观察，不增加强引用计数

仅仅为了访问对象，不应强迫调用方传入智能指针：

cpp
void inspect(const User& user);          // 只读借用
void take(std::unique_ptr<User> user);   // 转移所有权

用 weak_ptr 打破循环引用

父对象拥有子对象、子对象只回指父对象时：

cpp
struct Child;

struct Parent {
    std::shared_ptr<Child> child;
};

struct Child {
    std::weak_ptr<Parent> parent;
};

使用前将弱引用临时提升：

cpp
if (auto parent = parent.lock()) {
    parent->update();
}

选择哪一侧使用 weak_ptr 取决于所有权设计，不是固定规则。

控制块保存共享管理信息

shared_ptr 的控制块通常保存强引用计数、弱引用计数、删除器和分配器信息。不要从同一个裸指针构造两套独立的 shared_ptr：

cpp
User* raw = new User();

std::shared_ptr<User> first(raw);
std::shared_ptr<User> second(raw); // 两个控制块，可能 double free

应当复制已有的 shared_ptr：

cpp
std::shared_ptr<User> second = first;

make_shared 通常合并分配

cpp
std::shared_ptr<User>(new User());

通常先为 User 分配内存，再为控制块分配内存。

cpp
std::make_shared<User>();

通常一次申请能够同时容纳控制块和 User 的内存，再使用原地构造初始化对象：

text
[控制块 | User 对象]

它通常分配次数更少、局部性更好。代价是强引用归零后，User 会立即析构，但若仍有 weak_ptr，包含对象存储和控制块的整块内存通常要等弱引用也归零后才能释放。

shared_from_this 复用现有控制块

cpp
class Player
    : public std::enable_shared_from_this<Player> {
};

基类内部维护类似弱引用的关联。对象首次被兼容的 shared_ptr 管理时，现有控制块会与该关联绑定：

cpp
auto player = std::make_shared<Player>();
auto self = player->shared_from_this();

self 与 player 共享控制块。不要使用：

cpp
std::shared_ptr<Player>(this); // 可能创建第二个控制块

栈对象、仅由 unique_ptr 管理的对象，或构造期间尚未建立共享管理关系的对象，不能正常使用 shared_from_this()；它通常会抛出 std::bad_weak_ptr。

异步回调先决定是否延长生命周期

捕获 this 只保存裸指针，对象先销毁时会悬空：

cpp
executor.post([this]() {
    play();
});

任务必须执行并保持对象存活时，捕获强引用：

cpp
auto self = shared_from_this();
executor.post([self]() {
    self->play();
});

对象销毁后任务可以取消时，捕获弱引用：

cpp
std::weak_ptr<Player> weakSelf = weak_from_this();
executor.post([weakSelf]() {
    if (auto self = weakSelf.lock()) {
        self->play();
    }
});

普通局部变量按引用捕获也有同样风险：

cpp
std::function<void()> makePrinter() {
    int value = 42;
    return [&value]() { // 返回后悬空
        std::cout << value;
    };
}

此时应按值捕获：

cpp
return [value]() {
    std::cout << value;
};
