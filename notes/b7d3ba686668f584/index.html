生产者消费者：手写阻塞队列

记录题目约束、建模思路与推导。

题目要求与接口约束

实现一个有界阻塞队列 SimpleBlockingQueue<T>，支持：

java
void put(T value) throws InterruptedException;
T take() throws InterruptedException;
int size();

要求：

  • 队列满时，生产者调用 put() 阻塞等待。

  • 队列空时，消费者调用 take() 阻塞等待。

  • 多个生产者、多个消费者同时访问时不能破坏队列状态。

  • 不能使用 BlockingQueue 直接完成核心逻辑。

  • 正确处理中断。

共享状态、等待条件与唤醒

共享资源是内部队列，必须被同一把锁保护。

需要维护的不变量是：

text
0 <= queue.size() <= capacity

生产者逻辑：

text
队列满 -> 等待
队列未满 -> 入队 -> 唤醒等待线程

消费者逻辑：

text
队列空 -> 等待
队列非空 -> 出队 -> 唤醒等待线程

注意：wait() 必须放在 while 中。线程被唤醒后，只能说明“队列状态可能变化了”，不能保证当前线程需要的条件已经满足。

配套代码与检查要点

对应 Java 文件：

  • ProducerConsumerPractice.java

配套文件已有实现，阅读与复查重点如下：

  1. put() 中队列满时等待。

  2. take() 中队列空时等待。

  3. 入队和出队后通知其他等待线程。

  4. 确认 main() 能正常结束。
