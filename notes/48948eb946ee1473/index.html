AI 与大模型

基础知识

1.1 基础知识

大模型本质是通过已有的数据集，训练出一个语义空间。不同的输入会被分解成一个 token，大模型通过多维度词典空间和输入 token 的点积来寻找下一个最相关的词。

如何根据现有数据训练出这个语义空间，再从语义空间解码回原来的数据，也就是编码 => 解码的流程，是要解决的根本问题。

1.2 神经网络

多层“线性变换 + 非线性激活”的嵌套。

神经网络由多个神经网络层组成，而一层神经网络层由多个神经元组成，核心规律是浅层检测简单特征，深层检测复杂特征。

例如：

输入：一张猫的图片（像素）

text
第1层神经元（简单特征）
├── 神经元A：检测到"一条横线"
├── 神经元B：检测到"一条竖线"
├── 神经元C：检测到"一个角"
└── 神经元D：检测到"一个亮斑"

         ↓ 上一层的输出作为这一层的输入

第2层神经元（组合特征）
├── 神经元E：横线+竖线+角 → 检测到"一个三角形"
├── 神经元F：两个角+亮斑 → 检测到"一只眼睛"
└── 神经元G：多条线 → 检测到"毛发纹理"

         ↓

第3层神经元（高级特征）
├── 神经元H：两只眼睛+三角形 → 检测到"猫脸"
└── 神经元I：毛发+猫脸 → 检测到"这是一只猫"

1.2.1 神经元

表达为以下公式：y = σ(w1x1 + w2x2 + w3x3 + b)

其中：

  1. 加权求和 w：把每个输入 xi 乘以一个权重 wi，加起来，再加一个偏置 b

  2. 激活函数 σ：对求和结果做一次非线性变换

  3. 偏置参数 b：函数截距

训练的过程就是找到一组 W 和 b，让模型预测尽可能接近正确答案。

1.2.2 训练过程

训练的过程主要分为以下几个环节：

前向传播 => 计算 Loss => 反向传播 => 参数更新（梯度下降）

  1. 前向传播：本质就是函数嵌套，每一层都是一个函数 fi(x) = σ(Wi⋅x + bi)，多层串起来输出 f3(f2(f1(x)))

  2. 计算 Loss：评估这一次训练结果和目标结果的偏差

  3. 反向传播：根据链式法则把误差向前传，得到每层参数的梯度

  4. 参数更新：根据梯度下降调整参数，让误差不断收敛

补充概念：

  • 过拟合：在数据集中表现良好但在未知数据中表现过差

  • 梯度下降：根据偏导数调整参数方向，让误差尽量收敛到最小

  • Transformer：多头注意力机制
