适用条件与不适用边界

  • 题目要求连续子数组或连续子串。

  • 需要求最长、最短、固定长度匹配，或满足条件的区间数量。

  • 窗口状态可以增量维护，例如字符频次、窗口和、不同字符数量。

如果是求和问题且数组里可能有负数，普通滑动窗口通常不适合，优先考虑前缀和。

统一写法

优先使用 left / right 双指针表达窗口，不用一开始就记 i - len 这类公式。

  • right：当前刚进入窗口的右边界。

  • left：当前窗口的左边界，也是命中答案时要记录的起点。

  • right - left + 1：当前窗口长度。

固定长度窗口也按这三步写：

win[s[right] - 'a']++;

while (right - left + 1 > len) { win[s[left] - 'a']--; ++left; }

if (right - left + 1 == len && win == need) { ans.push_back(left); }
