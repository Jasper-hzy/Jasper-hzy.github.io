算法练习

小红书高频算法题清单

这份清单单独记录小红书/内容社区类岗位面试里更值得优先快速过的算法题。公开面经来源比较分散，因此这里按“内容平台常见题型 + 面经高频算法模型”整理，用于快速刷题和复习，不等同于官方题库。

第一优先级

  • LC146 LRU 缓存：哈希表 + 双向链表，考察缓存淘汰策略和 O(1) 数据结构设计。

  • LC215 数组中的第 K 个最大元素：TopK，小根堆或快速选择。

  • LC3 无重复字符的最长子串：滑动窗口，字符串去重。

  • LC15 三数之和：排序 + 双指针 + 去重。

  • LC42 接雨水：双指针 / DP / 单调栈。

  • LC206 反转链表：链表基础指针操作。

  • LC25 K 个一组翻转链表：链表分组反转，边界和递归/迭代指针处理。

  • LC23 合并 K 个升序链表：小根堆或分治。

  • LC53 最大子数组和：Kadane / 动态规划。

  • LC121 买卖股票的最佳时机：一次交易，历史最低价或股票状态机。

  • LC122 买卖股票的最佳时机 II：多次交易，贪心或股票状态机。

  • LC300 最长递增子序列：DP + 二分牌堆模型。

树 / 图 / BFS DFS

  • LC200 岛屿数量：网格 DFS/BFS + visited。

  • LC994 腐烂的橘子：多源 BFS，按层计时。

  • LC236 二叉树的最近公共祖先：二叉树递归返回值。

  • LC102 二叉树的层序遍历：BFS 层序模板。

  • LC103 二叉树的锯齿形层序遍历：层序遍历 + 隔层反转。

  • LC199 二叉树的右视图：层序遍历取每层最后一个，或右优先 DFS。

链表补充

  • LC21 合并两个有序链表：双指针合并。

  • LC19 删除链表的倒数第 N 个结点：快慢指针 + dummy。

  • LC142 环形链表 II：快慢指针找环入口。

数组 / 字符串补充

  • LC88 合并两个有序数组：从后往前双指针。

  • LC56 合并区间：排序 + 合并重叠区间。

  • LC54 螺旋矩阵：四边界收缩。

  • LC5 最长回文子串：中心扩展。

DP / 回溯补充

  • LC72 编辑距离：二维 DP，插入/删除/替换。

  • LC1143 最长公共子序列：二维 DP。

  • LC46 全排列：回溯，路径 + used。

复习顺序建议

  1. LRU、TopK、滑动窗口、三数之和、接雨水。

  2. 链表三件套：反转链表、K 个一组、合并 K 个链表。

  3. BFS/DFS：岛屿数量、腐烂橘子、层序遍历变种。

  4. DP：最大子数组和、股票、LIS、编辑距离、LCS。
