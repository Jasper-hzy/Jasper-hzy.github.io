三线程顺序打印 ABC

题目要求与退出条件

有三个线程：

  • 线程 A 只打印 A

  • 线程 B 只打印 B

  • 线程 C 只打印 C

要求最终输出：

text
ABCABCABCABCABC

总共循环 5 次。

要求：

  • 不能使用 Thread.sleep() 控制顺序。

  • 可以使用 Semaphore、synchronized + wait/notifyAll 或 ReentrantLock + Condition。

  • 程序最终正常退出。

用信号量传递执行权

这题最适合先用 Semaphore 做，因为它天然表达“执行权传递”：

text
A 打印后放行 B
B 打印后放行 C
C 打印后放行 A

初始状态：

text
A semaphore = 1
B semaphore = 0
C semaphore = 0

也就是 A 先执行，B 和 C 一开始阻塞。

配套代码与检查要点

对应 Java 文件：

  • ABCPrinterPractice.java

配套文件已有实现，阅读与复查重点如下：

  1. 初始化三个 Semaphore。

  2. 在 printA/printB/printC 中等待自己的许可。

  3. 打印后释放下一个线程的许可。

  4. 确认输出顺序稳定为 ABCABCABCABCABC。
