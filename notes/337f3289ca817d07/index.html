基础语义

参数传递怎样表达语义

形式是否可空能否修改原对象典型含义
T value不适用否，操作的是独立参数复制、移动或接收所有权
T& value否是借用并修改
const T& value否否只读借用
T* value通常可以可以可空借用
const T* value通常可以否可空只读借用

引用绑定不会自动触发拷贝或移动构造。引用和裸指针也不管理生命周期，函数将其长期保存时必须确认被引用对象活得更久。

小类型通常按值传递：

cpp
void setAge(int age);
void setEnabled(bool enabled);

返回新对象时也通常按值返回，依靠返回值优化和移动语义：

cpp
User createUser();
std::string getName();

不要返回局部对象的引用：

cpp
const std::string& makeName() {
    std::string name = "xplay";
    return name; // 悬空引用
}

const 与指针

记忆方式：把 * 当作分界线。

const 在 * 左边就锁数据，在 * 右边就锁指针。

声明能否修改 *p能否修改 p含义
const T* p否是指向只读数据的普通指针
T* const p是否指向可修改数据的常量指针
const T* const p否否指向只读数据的常量指针

const 在 * 左边：锁数据

cpp
int first = 1;
int second = 2;
const int* p = &first;

// *p = 10;  // 错误：不能通过 p 修改数据
p = &second; // 正确：p 可以换地址

这里限制的是“不能通过 p 修改数据”，不代表原对象本身一定不可修改：

cpp
first = 10; // 正确

int const* p 与 const int* p 含义相同。

const 在 * 右边：锁指针

cpp
int first = 1;
int second = 2;
int* const p = &first;

*p = 10;    // 正确：可以修改数据
// p = &second; // 错误：p 不能换地址

* 两边都有 const

cpp
int value = 1;
const int* const p = &value;

// *p = 10;     // 错误：不能通过 p 修改数据
// p = &second; // 错误：p 不能换地址

对象布局与内存对齐

在常见平台上，成员需要放在满足自身对齐要求的地址，结构体大小也通常是其对齐值的整数倍：

cpp
struct Data {
    char a;
    int b;
    char c;
};

若 int 大小和对齐均为 4，布局通常是：

text
偏移 0：a
偏移 1～3：成员间填充
偏移 4～7：b
偏移 8：c
偏移 9～11：尾部填充

因此 sizeof(Data) 通常是 12，alignof(Data) 通常是 4。尾部填充保证 Data 数组中下一个对象的成员仍然正确对齐。

调整成员顺序可以减少填充：

cpp
struct BetterData {
    int b;
    char a;
    char c;
}; // 通常为 8 字节

具体布局属于 ABI 实现细节，不能脱离目标平台和编译选项假定。

static 的三种常见语义

位置生命周期主要作用
文件作用域静态存储期当前翻译单元私有，具有内部链接
函数内部静态存储期多次调用共享同一对象
类内部静态存储期所有实例共享同一成员

C++11 起，函数局部 static 的初始化过程线程安全，但初始化后的对象不会自动变成线程安全对象：

cpp
User& getUser() {
    static User user; // 只保证初始化一次
    return user;
}

多个线程并发调用 user.update() 是否安全，仍由 User 自身实现决定。
